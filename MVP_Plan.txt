S Ring
원형 24시간 시간표 앱 · React + TypeScript · iOS / Android

앱 개요
앱 이름
S Ring — 원형 다이얼로 하루를 설계하는 시간표 앱. S Diary와 커플 브랜드.
기술 스택
React Native + TypeScript / Expo (iOS · Android 동시 출시)
상태 관리
Zustand (경량, 로컬 중심 앱에 적합)
로컬 저장소
MMKV (빠른 키-값) + 구조 데이터는 SQLite (expo-sqlite)
데이터 보안
완전 로컬 저장. 서버 전송 없음. JSON 내보내기만 지원.
다크모드
시스템 설정 연동 + 앱 내 수동 전환 지원
핵심 기능 (MVP)
🕐 원형 시간표 (메인)
24시간 이중 링 다이얼. 안쪽 링(0~12시) + 바깥 링(12~24시). 호(arc)를 탭/드래그하면 스케줄 생성. 랜덤 색상 자동 배정.
📋 리스트 보기
시간순 나열. 하루 / 한달 / 연도별 accordion 자동 그룹핑. 최근 항목만 펼쳐진 채로 시작. 나머지는 접힌 상태.
📝 상세 / 편집 화면
제목, 시간(시작~끝), 색상 피커, 메모. 수정 및 삭제 가능. 삭제는 confirm 다이얼로그.
💾 JSON 내보내기
전체 또는 날짜 범위 지정 내보내기. .json 파일로 기기 저장 또는 공유 시트 전송.
화면 구성 (3 screens)
01
Ring View — 메인 화면. 상단에 날짜 표시 + 뷰 전환 버튼(Ring / List). 24시간 이중 원형 다이얼. 호를 탭하면 신규 스케줄 작성, 기존 호를 탭하면 상세 이동. 하단에 오늘 스케줄 요약 바.

02
List View — 동일 상단 날짜 + 전환 버튼. 스케줄을 시간순 나열. 연도 → 월 → 일 3단계 accordion. 기본 상태: 오늘 날짜 섹션만 오픈. 각 항목에 색상 도트 + 제목 + 시간 표시.

03
Detail / Edit View — 제목 입력, 시작·종료 시간 피커, 색상 선택(팔레트 + 커스텀), 메모 텍스트. 저장 / 삭제 버튼. 신규 생성과 수정 모두 동일 화면 재사용.

원형 다이얼 UX 설계
24시간을 이중 링으로 표현. 안쪽 링: 0시~12시 (AM) · 바깥 링: 12시~24시 (PM). 스케줄은 해당 링 위에 호(arc)로 렌더링. 색상은 랜덤 배정 후 수정 가능.

링 위 빈 영역 탭 → 해당 시간대 기본값으로 신규 작성 화면 진입
기존 호(arc) 탭 → 해당 스케줄 상세 화면 진입
스케줄이 겹치는 경우 호를 안쪽으로 레이어 표시 (최대 3단)
현재 시각 바늘(침) 표시로 지금 위치 확인 가능
핀치 줌으로 특정 시간대 확대 (선택 구현)

S Ring vs S Diary 브랜드 정의
S Diary
날짜 기반 감정 기록. 캘린더 중심. 감성적. 과거를 돌아보는 앱.
S Ring
시간 기반 일정 설계. 원형 다이얼 중심. 구조적. 하루를 설계하는 앱.
두 앱 모두 "S" 브랜드 아래, 로컬 저장 + 미니멀 디자인 원칙 공유. 나중에 같은 디자인 시스템으로 묶어 패밀리 앱 구성 가능.
