# S Ring 🕒⭕

React Native + TypeScript 기반으로 개발한 원형 24시간 시간표 앱입니다.<br>
하루의 시간을 리스트가 아닌 원형 다이얼(Ring UI)로 시각화하여 사용자가 자신의 하루를 직관적으로 설계하고 관리할 수 있도록 구성했습니다.<br>
모든 일정 데이터는 기기 내부에만 저장되는 로컬 기반 구조이며,외부 서버 없이 안전하게 동작합니다.<br>
핵심은 단순한 일정 기록이 아니라 **“하루를 시각적으로 설계하는 경험”**입니다<br><br>
